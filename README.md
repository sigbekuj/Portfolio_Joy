# Personal Developer Portfolio

A personal portfolio website built to showcase my software development skills, projects, technical experience and professional background.

The website was developed using HTML, CSS and JavaScript, with a focus on responsive design, interactive functionality and a straightforward user experience.

## Overview

This portfolio serves as a central place to explore my development work, learn about my technical background and get in touch with me.

It demonstrates my ability to build responsive web interfaces, work with JavaScript functionality and integrate third-party services.

## Features

- **Responsive design:** Layout designed to provide a consistent experience across different screen sizes.
- **Project showcase:** A dedicated space to present software development projects and technical work.
- **Contact functionality:** Integration with a third-party email API to support asynchronous message submission.
- **Error handling:** JavaScript handling for asynchronous requests and potential API errors.
- **Interactive interface:** JavaScript functionality to improve the user experience.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive layouts |
| JavaScript | Interactive functionality |
| Third-party Email API | Contact form integration |
| Git & GitHub | Version control and source code management |

## Getting Started

### Prerequisites

- A modern web browser.
- Git installed on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/sigbekuj/Portfolio_Joy.git
```

Navigate into the project directory:

```bash
cd Portfolio_Joy
```

Open `index.html` in your browser, or use the VS Code Live Server extension to run the website locally.
